## What this gives the ward

Short, friendly web addresses like zippa.run/abcBulletin that send people on to the real page. Every QR code WardForward prints uses the short link, so when a destination changes you change it once on zippa.run, and every printed flyer keeps working.

## How zippa.run works

zippa.run is a separate service. Anyone can ask to join; an operator approves each request and ties the account to your ward's prefix, a few letters that start every link your ward makes (in these examples, "abc"). Once approved, the role account can make any link that starts with the prefix. A name that doesn't start with it, such as a link for the stake website, is a separate request the operator approves.

WardForward can't make zippa.run links for you. You make them on zippa.run and paste them into WardForward (steps 8 and 9).

## Steps

- **1.** If you haven't yet, send the access request from the role account (step 1): [app.zippa.run](https://app.zippa.run), Sign in with Google, role account, then fill in the form. Wait for approval. Ask for the same prefix your ward uses on WardForward (it shows on your ward's home page as "Public portal: /p/your-prefix").
- **2.** Once approved, sign in to [app.zippa.run](https://app.zippa.run) as the role account.
- **3.** Make one short link per destination. Start every name with your prefix and make the rest guessable. Point each one at its real address.
- **4.** Write each short link down next to where it points. You'll paste them into WardForward in the next steps.

## Link name ideas

- abcBulletin: the ward bulletin.
- abcWelcome: the new-member form.
- abcDiscord: the ward's chat invite.
- abcBishop, abcSetApart, abcTemple, abcTithe: the booking pages from step 5.
- abcLinks: the ward's public portal (step 8 tells you its address).
- abcServe and abcHelp: the service pages (step 9).

## Done when

- The role account is a zippa.run creator on the ward's prefix.
- There is one short link for each destination you'll share.

## Notes

**Names are permanent.** Once a short link name is taken it can never be used again, by anyone. Choose names carefully. What you can always change is where a link points.

**Never delete a printed link.** If a page moves, point the old short link at the new place. Several short links may point at the same page.

**The links belong to the calling.** Because the role account makes them, the next Executive Secretary keeps them all.

If your request is declined you can't apply again from the same account; contact the zippa.run operator instead.
